#SimpleEqualizer

Simple Equalizer is a Windows equalizer available as both a standalone application and a VST3 plugin.

#Download

Download the latest installer from GitHub Releases.

#Installation

Download and run Simple Equalizer Setup.exe.

Follow the installer steps.

Find the standalone app in the Start menu under Simple Equalizer.

The installer places the VST3 plugin in the standard Windows VST3 folder:

C:\Program Files\Common Files\VST3

Your DAW may need to be restarted or rescanned before the plugin appears.

#Using Simple Equalizer

Standalone: launch Simple Equalizer from the Start menu.

VST3: open it from your DAW’s plugin browser after scanning for VST3 plugins.

#System Requirements

64-bit Windows

A DAW that supports VST3, to use the plugin version

If you find a problem or have a suggestion, open an issue.
